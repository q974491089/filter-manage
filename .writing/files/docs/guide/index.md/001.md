# 简介

Filter Manage 是一个 Windows 桌面应用程序，用于管理 ICC 颜色配置文件和 NVIDIA 显卡颜色设置。

## 功能特性

- **ICC 配置文件管理** — 扫描系统目录，一键切换 ICC 配置文件
- **NVIDIA 颜色调节** — 亮度、对比度、伽马、数字振动
- **配置预设** — 保存当前设置，一键切换不同场景（游戏/日常）
- **实时预览** — 参考图片实时预览调节效果
- **日夜模式** — 支持亮色/暗色主题切换，保护眼睛

## 主题系统

Filter Manage 采用精致的设计语言，提供优质的视觉体验：

### 亮色模式
- 清新明亮的白色基调
- 适合日间使用，减少视觉疲劳
- 精致的阴影和边框效果

### 暗色模式
- 深邃优雅的深色背景
- 适合夜间使用，保护眼睛
- 柔和的对比度设计

**切换方式**：点击界面右上角的太阳/月亮图标即可一键切换主题。

## 技术栈

- 前端：React 18 + TypeScript + Tailwind CSS
- 后端：Rust (Tauri 2.x)
- 平台：Windows 10/11
