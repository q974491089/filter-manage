# 使用方法

## ICC 配置文件管理

1. 启动应用后，左侧面板显示系统中所有可用的 ICC 配置文件
2. 点击任意配置文件即可切换
3. 支持导入外部 `.icc` / `.icm` 文件

## NVIDIA 颜色调节

通过滑块调节以下参数：

| 参数 | 范围 | 说明 |
|------|------|------|
| 亮度 | -125 ~ 125 | 0 为默认值 |
| 对比度 | -82 ~ 82 | 0 为默认值 |
| 伽马 | 0.1 ~ 3.0 | 1.0 为默认值 |
| 数字振动 | 0 ~ 100 | 50 为默认值 |

## 配置预设

### 保存配置

1. 调节好参数后，点击「保存配置」
2. 输入配置名称（如「游戏模式」「日常模式」）
3. 配置保存成功

### 加载配置

点击已保存的配置名称即可一键应用所有设置。

## 预览功能

应用内置参考图片预览区域，调节参数时可实时观察效果变化。
