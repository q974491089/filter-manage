## 系统要求

- Windows 10/11 (64-bit)
- NVIDIA 显卡（颜色调节功能需要）
- WebView2 Runtime（Windows 11 已内置，Windows 10 安装包会自动安装）

## 安装步骤

1. 下载 `.exe` 安装包
2. 双击运行，按提示完成安装
3. 启动 Filter Manage
