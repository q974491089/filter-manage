# 安装

## 下载

前往 [Releases](https://github.com/q974491089/filter-manage/releases) 页面下载最新版本。

提供以下安装包格式：

| 文件 | 说明 |
|------|------|
| `Filter Manage_x.x.x_x64-setup.exe` | NSIS 安装包（推荐） |
| `Filter Manage_x.x.x_x64_en-US.msi` | MSI 安装包 |

## 系统要求

- Windows 10/11 (64-bit)
- NVIDIA 显卡（颜色调节功能需要）
- WebView2 Runtime（Windows 11 已内置，Windows 10 安装包会自动安装）

## 安装步骤

1. 下载 `.exe` 安装包
2. 双击运行，按提示完成安装
3. 启动 Filter Manage
