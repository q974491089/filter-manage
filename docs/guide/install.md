## 系统要求

- Windows 10/11 (64-bit)
- 显卡和显示器支持对应的颜色调节能力；本版改善了 AMD 兼容性，具体支持情况以驱动和显示器为准
- WebView2 Runtime（Windows 11 已内置，Windows 10 安装包会自动安装）

## 安装步骤

1. 下载 `.exe` 安装包
2. 双击运行，按提示完成安装
3. 启动 Filter Manage
