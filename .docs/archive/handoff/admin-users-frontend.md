# 用户列表 — 前后端交接

**日期**：2026-11-10。**状态**：本地实现与联调完成，未部署。

契约以 [管理端用户列表](../../api/admin-users.md) 为准：`GET /api/internal/icc/users`，ADMIN cookie，分页/全库搜索/状态与登录方式筛选。禁止客户端 Bearer 或 EDITOR 读取 PII；前端使用实际 session role 隐藏入口并保护 `/users`。

后端只读注册账号与登录身份、会话活跃时间，不碰认证 mutation 或匿名投稿迁移。前端无删除/禁用按钮；旧请求不覆盖新结果。

预发与线上都复用 market 的 `/api/internal/icc` 路由；必须部署 API market 和 admin 两个仓库，预发数据库不等于线上。

完成后补充真实验证结果，再写入共享 `SYNC_STATUS.md` 完成信号。
## 已完成

前后端契约已接入；验证详情见 [本地完成与验证](../../api/admin-users.md)。前端 21 项测试、类型检查、生产构建、lint，后端全量测试/真实 PostgreSQL 集成及 vet 通过；浏览器核对 ADMIN/EDITOR、全库搜索、组合筛选、空态、窄屏布局。仍未提交或部署。

## 自增用户 ID 接入（2026-11-11）

用户列表 `id: string` 现为数据库自增 bigint 的十进制字符串；直接展示和复制，不能 `Number(id)`。后台 ID 列适配数字编号；服务端按数字 ID 排序并支持 ID 子串搜索。账号测试阶段的一次性重置发生于 market 启动迁移，详情见 [管理端用户列表](../../api/admin-users.md)。客户端投稿身份仍为独立 UUID，不需要更改 Rust/React 登录协议。
