# Filter Manage v0.6.2 更新公告

这次更新重点解决切换方案、游戏自动监听后颜色偶尔不生效的问题，并升级了分享与投稿的预览体验。

## 方案切换更稳定

修复部分电脑点击方案后只生效一下、随后颜色回退的问题。切换方案后，不用再拖动一次滑块才能保持效果，同时减少了切换时的闪动。

## 游戏自动监听更可靠

改善游戏启动、显示模式变化和切回前台时的颜色保持，修复自动应用方案后偶尔仍需拖动滑块的问题。手动调整后会以你的新设置为准。

## AMD 与分辨率兼容性改进

修复部分 AMD 显示器被误判为不支持色彩饱和度的问题。应用或导入分享方案时，会检查本机支持的分辨率和刷新率；遇到不兼容的设置，颜色仍可正常应用，并给出说明。

## 新增游戏场景预览

分享、投稿和导入窗口加入 CS2、无畏契约、三角洲行动场景，可切换场景比较模拟效果、放大查看。分享链接和投稿会保留你选择的场景，官网分享页也同步支持。

预览用于比较方案，实际画面效果以你的显示器为准。

## 其他改进

- 修复场景切换时图片错位、切换控件位置异常等问题。
- 优化重复查看效果时的等待，完善问题反馈用的调试报告。
- 加入实验性的 NVIDIA 专用调色支持，后续逐步开放。

本次继续保持现有使用方式，无需登录。
