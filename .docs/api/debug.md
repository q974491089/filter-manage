# 方案应用后的延迟回读

当前报告中的即时 GetDeviceGammaRamp 回读只说明系统层当时的曲线，不能证明画面持续采用它。

手动 apply_display_color_config 成功且实际后端为 standard 时，在活动调试会话中建立最终 LUT + generation 快照，约 250ms 与 1000ms 后只读回读。日志分类为 verify-delayed，包含方案、实际目标设备、代号、实际经过的毫秒数、全 RGB 高字节最大差与期望/实际 R 中间调。

整个回读持颜色门闩复核代号，后续滑块/方案/后端切换使旧任务不再读取；原调试会话结束后不得记录到新会话。回读失败保留为失败，不当成一致。不重新注册 ICC，不写颜色。NVIDIA 私有曲线后端不使用 GDI 回读判断其效果。

环境快照保留新接口给出的明确 hdr 状态；旧高级颜色位标注可能包含 HDR 与 SDR ACM，不再将其单独当作 HDR 证据。
